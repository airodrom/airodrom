# OpenCode Runtime Adapter V1

The adapter implements [ADR 0005](adr/0005-opencode-execution-boundary.md). Its identity is `opencode`; its output is execution evidence only.

The initial supported surface is OpenCode CLI **2.0.20**, macOS, and local Ollama inference. Official [v2 commands](https://opencode.ai/v2/docs/cli/commands/), [configuration](https://opencode.ai/v2/docs/config/), [permissions](https://opencode.ai/v2/docs/permissions/) and [local model discovery](https://opencode.ai/v2/docs/models/) describe the upstream interfaces. The installed CLI's help and the official `v2.0.20` source tag were checked as well. V1 CLI flags and configuration are incompatible with this surface. Other versions, operating systems and external providers fail closed pending their own qualification.

Host composition accepts an `opencode` option with `enabled: true`, an installed absolute `executable`, a model such as `ollama/qwen3-coder:30b`, and an optional timeout of at most 120000 milliseconds. Availability requires the installed version and selected local model. No login is required for the local provider; status returns a category, never credentials. The [official installation page](https://opencode.ai/v2/docs) lists supported installers. Installing remains separate from enabling an adapter.

An operator registers a Mission with `preferred_agent: 'opencode'`, no fallbacks, and immutable `local_only` privacy with `providers: ['local']` and `billing_classes: ['local']`. New general Missions without an explicit runtime freeze the OpenCode default with this bounded local-only policy. See [cutover and rollback](DEFAULT-RUNTIME-CUTOVER.md). A manifest must explicitly permit local reasoning. The canonical authority, filesystem scope, localhost policy, lease and ContextPack gates still apply.

Execution accepts at most eight declared existing files, each at most 12000 bytes, and a total input at most 24000 bytes. Symlinks, hard links, traversal, secret-like content and memory database paths are rejected. New files and deletion are outside this initial contract. Only the supplied files are present in the runtime workspace. Read-only requests grant no edits. Shell, network tools, git, MCP, skills, subagents and external actions are denied. Registered tests run independently through Airodrom, with their definitions protected from the executor.

The runtime returns bounded JSON events. The adapter validates session correlation and the final result, removes raw tool arguments and diagnostics, redacts summaries, measures actual changed files, and returns file hashes, sizes and provenance. Claims of tests or authority never become verifier receipts. Instructions and context are absent from process arguments. Runtime logs, SQLite session state and caches stay in an isolated temporary directory that is removed after verified termination.

Upstream supports native session continuation. This adapter intentionally rejects it because previous personal context could survive correction or erasure. Host-authorized rework starts a new session and retrieves current canonical context. Repeated dispatch request IDs use the canonical Mission idempotency contract. Failures require explicit rework; there is no blind retry.

Qualification uses synthetic stores and a temporary repository. It exercises read-only work, one-file editing, artifact return, a registered test, independent repository checks, Acceptance and Settlement. Deterministic adversarial checks cover unavailable versions, workspace and scope violations, nonzero and malformed output, timeout, cancellation, duplicates, secret handling and authority escalation. The Memory V2 test stores one synthetic preference, supplies only its authorized retrieval, corrects it, forgets and erases it, rejects old packs, and checks fresh-session non-delivery. It does not inspect the operator's real private memory or activate production.

## Qualification evidence

On 2026-10-06, OpenCode 2.0.20 (`ollama/qwen3-coder:30b`, macOS arm64) passed isolated live read-only and one-file edit tasks, host-measured artifact return, protected registered tests, independent repository verification, explicit Acceptance and subsequent Settlement. Real timeout and cancellation terminated the private process group. The executable SHA-256 is recorded in [runtime qualification metadata](../config/agent-runtime-qualification-v1.json).

The canonical synthetic personal Memory V2 path passed remember, one-item bounded retrieval, correct use by the real runtime, correction, stale-pack denial, forget, canonical erasure, non-delivery after erasure, fabricated cache rejection and session reuse denial. An independent OS sandbox canary denied reading the fixture's actual SQLite store. No real private memory was inspected. Local deterministic tests also cover restart, malformed/nonzero output, secret redaction, undeclared writes, duplicate dispatch and authority denial.

Run `npm run test:opencode` for deterministic checks. `npm run test:opencode:live` explicitly exercises the installed local CLI/model with synthetic fixtures; it requires macOS and the selected model already running locally. Live qualification remains bounded to this exact surface. Missing optional result claim lists normalize to empty lists; malformed values and unknown fields fail closed, and actual file changes are always measured by the host. Pi remains available for compatibility; OpenCode is the canonical default for new general Missions; Pi typed plans and explicit saved runtime identities remain stable.
