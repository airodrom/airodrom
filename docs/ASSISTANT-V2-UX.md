# Assistant V2 UX implementation evidence

Normal terminal output now renders models, workers, connectors, Memory, sensitive metadata, Vault status and Mission state as readable text. Read-only commands offer explicit `--json` developer output. Manual preferences are checked with the existing qualified router before selection; a refused selection preserves the previous preference. Shell flags and pasted command prompts resolve locally. `/help` separates shell and interactive commands, and `/mcp` explains the separate shell transport.

Conversation Missions ask for a direct user answer in the existing `summary` field. Scoped work retains its previous reporting instructions. The response appears separately from model/locality/Memory and Response, Verification, Review and Settlement metadata. Canonical confinement, authority, budgets, qualification, erasure, connector injection protection, operator-only sensitive reveal and purpose-bound Keychain semantics are unchanged. No schema or permission migration is introduced. Presentation changes do not qualify an optional worker or automatically accept an answer.

Control Center uses allowlisted canonical event stages for Request, Context, Runtime, Execution, Verification, Acceptance and Settlement. Unobserved stages say so. Activity animates only while execution is observed; no completion percentage or time estimate is invented. Budget consumption is labelled as budget, not completion. Motion stops for review, paused/stale observations and reduced-motion preferences. Conversation detail keeps projected user-visible history on the left and lifecycle operations on the right. The existing current-context projection and generation checks continue to clear stale or forgotten content. Hidden reasoning and internal prompts remain private.

The native menu uses twelve cached template frames at four updates per second while busy. It invalidates the animation timer immediately on an idle observation, uses static approval/waiting/degraded/error states and respects macOS reduced motion. Aggregate status is observed once per second; helper errors do not change control-plane lifecycle. Existing service controls and private opener/lock boundaries remain intact. The terminal fallback samples the canonical SVG with ice/cyan highlights, blue face, indigo depth and a mint edge; compact, 256-color, 16-color and plain-text variants remain available.

Validation used synthetic data in isolated fixtures. The changed-surface suite covered CLI presentation and parsing, routing refusals, Memory erasure, connector redaction, OpenCode confinement, Pi removal and product projections. Browser checks covered responsive layouts, animated canonical execution, static Acceptance, reduced motion, authorization loss and delayed-response non-resurrection. Native checks exercised actual rendered frames, idle timer cancellation and existing helper safety. Both typechecks, public-source/syntax verification, package sanity and secret tree/history scans passed. The live local OpenCode smoke returned a natural greeting, answered “Your name is Aurora.” after a synthetic remember/restart, and stopped recalling the name after natural forget.

Only OpenCode 2.0.20 with `ollama/qwen3-coder:30b` is live-qualified. Codex/Work and Claude Code remain unavailable; Cursor remains denied. No real account was connected or real personal Memory inspected. The broad GitHub Actions workflow remains manually disabled; no hosted run was used for this UX pass. The existing trigger file is preserved because the Git credential lacks workflow-edit scope. Re-enabling the workflow later would restore its existing push/PR triggers.

Limitations: the adapter returns one bounded visible response, so streaming remains unavailable. Token usage, context capacity and measured price remain unavailable unless observed authoritatively. Model use of selected Memory cannot be measured; selection/delivery is reported separately. Menu idle/busy changes depend on the next aggregate observation. Hidden animation under reduced motion is intentional. No release, tag, registry publication, deployment or production activation is part of this pass.
