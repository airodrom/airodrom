# ADR 0013 — Governed browser and Arecibo product research

Status: Proposed. Concrete maintainer disposition, independent boundary review and focused qualification remain merge gates.

This replaces the browser-unavailable portion of accepted ADR 0012 only. Its private Vault, Unicode ingress, erasure and operator confirmation boundaries remain in force. Ordinary conversation remains governed by accepted ADR 0011.

Airodrom owns a typed Playwright host port behind CapabilityBroker. The new `web_read` scope is absent from default tasks. Browser research admits one sealed, bounded host Mission, a canonical worker Run, read leases, correlated per-action invocations, independent verification, owner Acceptance and separate Settlement. No OpenCode browser authority, arbitrary scripts, selectors, worker-created scope or recommendation implementation is admitted. Public requests authorize one exact HTTPS origin. Redirects and resources receive the same policy; TLS requests resolve and pin public addresses in the host. An owned deny-all proxy contains browser-native upstream traffic. Service workers, WebSockets, alternate transports and browser downloads remain blocked. Playwright-core is pinned; Chrome uses a fresh owned context and keeps its sandbox.

The host source profile registers the Arecibo sibling repository. Its current HEAD, existing dirty preimages, canonical product documents and bounded implementation files form the comparison baseline. Missing evidence remains unknown; marketing claims are documented, navigation observations do not establish working features, and untested account areas remain inaccessible. Website content is untrusted reference material and cannot select operations, change capability policy or authorize implementation. Report evidence is immutable private task content rehashed independently and before viewing or Acceptance; existing canonical erasure removes the task evidence directory. Opaque metadata retains the existing retention classifications. Public text/CSV/JSON downloads are limited to 48 KiB, exact operator approval and verified private task evidence. They serialize with browser operations and drain before report construction. No additional secret store or shadow Mission database is introduced.

Existing-account research is a separate explicitly confirmed operator Mission. Its sealed purpose binds origin, login URL and two current operator Vault references. Its authority ceiling allows only read-only repository/data access, internet and secret use; the existing taxonomy requires the Infrastructure level for secret use, with every other elevated flag absent. A canonical exact one-shot protected approval must be consumed before resolving either credential. A confirmed owner purpose may forward that single existing-login approval; website text, a model or a worker cannot. Values enter only the host Keychain-to-pinned-login transport, never page-fill, model context, chat, arguments, screenshots, ordinary input, logs or evidence. Authentication cookies are ephemeral and origin-bound. Private observation is limited to vetted navigation category identifiers; account screenshots remain unavailable. MFA and CAPTCHA stop the owned browser and require manual inspection; resumable live handoff is unavailable and cannot be bypassed. Account creation, purchases, settings changes, deletion and unsupported forms remain blocked; a public research authorization never permits them.

The Control Center displays durable browser and lifecycle events without percentages. Reports remain proposals until the owner reviews factual accuracy and accepts the current verified result. Source installation is separate from release, publication, deployment and production activation.

Compatibility: additive source profile, capability entry and typed host adapter; existing Memory, Vault dispositions, connector authorizations, conversation history and wave/fish renderer are preserved. Browser evidence resides beneath the existing private task erasure boundary. No live account or real credential is used for qualification. Pinned Playwright-core adds no install script or browser download. A missing reviewed browser engine or Arecibo baseline fails closed with a configuration explanation.

Alternatives rejected: unrestricted OpenCode browser tools; using remembered Arecibo capabilities as a baseline; persisting browser profiles or cookies; models declaring authorization; screenshots of authenticated pages; automatically implementing recommendations; simulated progress or automatic factual Acceptance.

Validation: focused domain/DNS/redirect/method policy, browser action schema, credential isolation/purpose/revocation, immutable evidence/staleness, canonical Mission routing/cancellation/Acceptance, a real browser synthetic-site smoke and declared type/package/source checks. Independent reviewers assess authority and privacy separately. See the [candidate qualification record](../BROWSER-RESEARCH-V1-QUALIFICATION.md). Broad duplicate regression and hosted CI remain outside this focused request unless a mandatory gate requires them.

Rollback: normal source revert before activation; preserve canonical Mission records and private evidence under existing retention/erasure policy. Historical research Missions never acquire new authority from a restored source version.
