# Primary execution runtime

OpenCode is the default primary runtime for new bounded general Missions. Pi is removed completely. No runtime, executable, session, rollback selector or dependency remains. Missing OpenCode, scopes or current context leads to WAIT/blocked without another runtime being selected.

Airodrom owns authority, capability policy, Memory V2, context selection, Mission lifecycle, leases, verification, Acceptance, Settlement, provenance, erasure and audit. OpenCode is a replaceable worker; its output is untrusted evidence. Registered typed file plans execute directly through the host Capability Broker as `host`, with no inference or agent process. Independent repository checks also use the host verifier.

Existing durable Pi identities remain historical provenance. They are never mapped to OpenCode or host execution. Resume, dispatch, capability invocation, new result publication and context building deny the removed identity. Missing old task identities are classified as the removed historical runtime. Create a fresh scoped Mission to do new work. No user memory or session data is deleted.

The authenticated browser and interactive CLI register fresh bounded OpenCode conversation Missions. Coding requires declared files and registered independent verification. MCP orchestrator tasks invoke typed host capabilities without agent sessions; reasoning-only mode uses explicit provider admission. The optional Pi-era Active Chat smoke is retired. Signed deterministic Level 1 reads remain host primitives.

See [removal and migration](PI-REMOVAL.md) and [ADR 0008](adr/0008-remove-worker-runtime.md). Distribution remains PRE-RELEASE. No release, publication, deployment or production activation is part of removal.
