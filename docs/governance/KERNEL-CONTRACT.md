# Kernel Contract

Kernel contract version **1.2.0** owns Mission authority, lifecycle/budget guards, Context Builder, memory governance, independent verification, Acceptance/Settlement, writer ownership, audit and runtime admission. `src/kernel/index.js` composes existing SQLite state machines. Apps own protocols under Kernel policy. Every change cites an [ADR](../adr/README.md). Breaking authority semantics require reviewed versioning and migration evidence.
